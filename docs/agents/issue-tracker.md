# Issue tracker: GitHub Issues

Human requests and specs for this repo live in GitHub Issues. Use the `gh` CLI for those operations.

## Conventions

- Create, read, list, comment on, label, and close issues with `gh issue`.
- When a skill says to publish a spec or fetch a human request, use GitHub Issues.
- Pull requests are not a triage request surface.

## Beads and rig work

Beads are used by Gas City to create and route implementation work to rigs. Use `bd` or `gc bd` for delegated work; do not use Beads as the intake tracker for human requests.
